# # AGROMAX - Plataforma Digital Agrícola

![Logo AGROMAX](https://i.imgur.com/EVoS3.png)

### Producimos con pasión, trabajamos por el futuro

Plataforma web moderna para la venta de insumos agrícolas: fertilizantes, foliares, insecticidas, herbicidas y herramientas.  
Enfocada en **alta conversión**, experiencia **mobile-first** y contacto directo por **WhatsApp**.

## ✨ Características principales

- Diseño tipo app móvil optimizado para agricultores
- Catálogo de productos con compra rápida
- Carrito de compras funcional
- Integración directa con WhatsApp Business
- Secciones de categorías y ofertas
- Totalmente responsive

## 🛠 Tecnologías utilizadas

- HTML5
- Tailwind CSS
- JavaScript (Vanilla)
- Font Awesome
- Vercel / Netlify (despliegue)
